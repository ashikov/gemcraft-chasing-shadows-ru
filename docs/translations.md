# Каталог переводов и выборочное извлечение

Формат `translations/ru.json` — JSON UTF-8, `schema_version: 1`. Сейчас в нём
только проверенный заголовок настроек; полный перевод не начат. Патчер прототипа
пока использует собственную проверенную константу: каталог не подключает массовые
замены и не меняет поведения установленного патча.

Верхний уровень содержит `game_sha256` (SHA-256 исходного SWF, до патча) и
`entries`. Каждая запись содержит:

- `id`: уникальный стабильный идентификатор контекста, а не английского текста.
- `category`: `static`, `actionscript` или `html`.
- `location`: объект адреса исходного использования. Для статической надписи —
  `character_id`, `tag_code`, при извлечении также `font_ids`.
- `source`: исходная строка с точными переносами и Unicode без нормализации.
- `source_sha256`: SHA-256 точных UTF-8 байтов `source`.
- `context`: заметка о месте и назначении надписи.
- `translation`: `null` означает отсутствие перевода, `""` — намеренно пустую строку.
- `mandatory_placeholders`: явный список обязательных токенов, например
  `["{count}"]`. Это синтетический пример, а не установленный синтаксис игры.
  Проверяется число вхождений каждого токена; автоматическое угадывание грамматики
  плейсхолдеров не выполняется.

Повторное извлечение делается в отдельный файл. Сопоставьте записи по `id`,
сравните `game_sha256`, `source_sha256` и `location`: изменение хеша источника
требует повторного просмотра перевода и контекста. Старый русский перевод нельзя
автоматически считать актуальным. Идентификатор `static.<character_id>` создаётся
инструментом для исходной версии; сохранность числового ID между версиями игры
не гарантируется и требует проверки адреса и контекста.

Проверка каталога:

```sh
python3 translation_catalog.py translations/ru.json
python3 translation_catalog.py output/selected-static.json --allow-missing
```

По умолчанию отсутствие перевода — ошибка. `--allow-missing` нужен для чернового
экспорта. Проверяются структура, повторные JSON-ключи и IDs, SHA источника,
недопустимые Unicode-суррогаты и явно заявленные плейсхолдеры. JSON-парсер проверяет
экранирование; перенос записывается как `\n`, кавычка как `\"`, обратный слеш как
`\\`. Для `html` дополнительно проверяется баланс вложенных тегов. Это базовая
проверка, не полноценная валидация диалекта Flash HTML, entities, атрибутов или
визуального отображения. Список разрешённых тегов и обязательных атрибутов пока
не определён. Для обычного текста HTML-проверка отключена.

## Статические надписи

Используйте оригинальный SWF из собственной установленной копии или проверенного
бэкапа. Текущий модифицированный файл игры не подходит при исходном SHA. Инструмент
только читает вход, не запускает игру и не применяет патч. Пример из корня проекта
(каталог `output/` должен существовать и оставаться исключённым из Git):

```sh
python3 extract_strings.py /путь/к/оригинальному/gc-cs-steam.swf \
  --original-sha256 c8eadc03a7e607086998695f7696ec22dd90d7b7859e3d10cdfabf40fc7bbad5 \
  --static-id 3016 --output output/selected-static.json
```

`--static-id` обязателен и может повторяться для разных IDs; массового экспорта
по умолчанию нет. Выход создаётся исключительно новым файлом без перезаписи.
Поддерживаются верхнеуровневые DefineText (11), DefineText2 (33) и таблицы символов
DefineFont2/3 (48/75), включая наследование font ID между TEXTRECORD. Глифы и
контуры в JSON не экспортируются. Проверенная игра использует DefineFont3.

Текстовые записи объединяются в одну строку в порядке глифов. Позиции, метрики,
цвета и переносы, заданные координатами, не реконструируются; этот экспорт не
является входом для универсального переписывания вёрстки. Вложенные DefineSprite
не обходятся, DefineFont/DefineFontInfo и внешние шрифты не поддерживаются.
Отсутствующие IDs, font ID и индексы глифов дают явную ошибку.

## ActionScript и HTML: отдельные следующие шаги

Для ActionScript нужно разобрать DoABC и выбрать именно текстовое использование:
QName класса/метода, индекс constant pool, offset инструкции и окружающий контекст.
Нельзя заменять весь pool по совпадению строки: то же значение может быть ключом
сохранения, идентификатором ресурса или имени класса. Экспорт и импорт байткода
в этом инструменте не реализованы. Исследовательский анализатор остаётся локальным
источником сведений; его дампы нельзя добавлять в Git.

Для HTML нужен отдельный экспорт DefineEditText (37) с character ID, HTML-флагом,
точными entities, тегами, переносами и сведениями о TextFormat/шрифте; динамический
HTML может формироваться в ActionScript. `category: html` готова для таких записей,
но автоматическое извлечение и изменение этих полей здесь не реализованы.

## Глоссарий

`translations/glossary.json` содержит пустой список `terms`. При подтверждённом
контексте добавляйте записи с `id`, `source`, `translation`, `context` и `notes`;
решения о названиях камней, навыков и механик принимайте по контексту. Этот файл —
заготовка рабочего глоссария, отдельной автоматической схемы для него пока нет.
Соблюдайте правовые ограничения проекта: оригинальные дампы и значительные объёмы
игрового текста остаются локальными до проверки прав.
