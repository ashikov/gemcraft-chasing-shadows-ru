# Аудит существующего прототипа

Перед изменениями: 14 успешных тестов; read-only проверка установленного SWF,
оригинального backup и 24 остальных файлов. Игра на инфраструктурном этапе
не запускалась. Существующие backup не перемещались и не удалялись.

## Сохранённые компоненты

`swf_geometry.py`: чтение/запись сжатого SWF с сохранением raw-тегов,
геометрия SHAPE, RECT/MATRIX, DefineFont3 и DefineText/2.
`build_prototype.py`: проверенный SHA-guard, рецепты кириллицы, патч одного
статического заголовка, структурная валидация остальных ресурсов.
`install_patch.py`: эксклюзивный backup, манифест с исходным/новым SHA,
атомарная замена с повторной проверкой текущего файла, hash-guarded restore.
Все они собственные инструменты, без игровых бинарных ресурсов.

Минимальные изменения: явно заданные пути CLI, configurable output/backup,
проверка перезаписи исходника, restore без зависимости от пересборки шрифта,
необязательный локальный inventory для verifier, перенос тестов в `tests/`.
Патч по-прежнему имеет исходный подтверждённый SHA; алгоритм глифов не изменён.

## Локальные материалы

`research-report.md` — историческое исследование до прототипа;
`prototype-report.md` — результат предыдущего этапа с runtime-свидетельствами.
Они содержат исходные строки, адреса байткода и локальный контекст, поэтому
сохранены локально и заменены в Git краткой документацией.

`inspect_swf.py` — исторический read-only probe AS/HTML/static с абсолютным
путём и исполнением на уровне модуля. Оставлен локально как свидетельство,
не является импортируемым поддерживаемым инструментом. Его выводы и дампы
могут содержать игровой текст/фрагменты кода и не публикуются.
Новый выборочный static extractor не утверждает полного охвата AS/HTML.
`runtime_window.ps1` связан с прежними GUI-проверками, оставлен локально,
не входит в инструменты проекта и никогда не вызывается тестами/CI.

`backups/` содержит оригинал и манифест; `output/` — производный SWF;
`artifacts/` — изображения и локальные свидетельства; `typography-local.json`
и другие JSON-дампы — результаты исследования. Все исключены из Git.
`reference-fonts/` — прежние референсы; не нужны для сборки и не публикуются.

## Зависимости и пробелы

Основной pipeline использует стандартную библиотеку Python; pytest и Ruff —
разработка, Pillow — только optional preview. FFDec/Bezel/LLM не требуются.
CLI не запускает игру. Тесты проверяют backup/restore на временных копиях;
они не доказывают поведение файловой системы при отключении питания или
совместимость с неизвестными обновлениями игры. Read-only SHA сверка
подтверждает сохранность установки, но не заменяет проверку GUI.

## Итоговая проверка инфраструктуры

40 тестов проходят: 35 синтетических и 5 локальных. Ruff, compileall и проверка
каталога проходят. Сборка из оригинального backup даёт тот же подтверждённый
SHA патча. Установка и все существующие backup-файлы сверены по SHA до/после;
они не изменены. Проверки из чистой копии staged-файлов не требуют игровых
ресурсов. Независимое read-only ревью выявило alias выходного файла сборки:
регрессионный тест воспроизвёл риск, затем добавлен отказ для symlink/hardlink
у SWF и JSON-отчёта до любой записи. Последовательность apply/restore также
проверена на изолированных копиях настоящего оригинала.

Аудит содержимого Git: только собственный код, синтетические фикстуры,
документация, конфигурация и одна короткая запись Options/Настройки.
Сырые отчёты, изображения, дампы, оригинальные и производные игровые файлы,
шрифты и backup исключены; известных шаблонов секретов не обнаружено.
Это проверка конкретного набора файлов, не юридическое подтверждение прав.
