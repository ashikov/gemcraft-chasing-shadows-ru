# План инфраструктурных изменений

Исходная точка: 14 тестов проходят; установленный патч воспроизводится побайтово;
backup проверен по SHA-256. Установку и backup не менять.

1. Сохранить геометрию SWF и рецепты шрифта без изменений. Перенести только тесты.
2. Явно настраивать пути CLI; сохранить формат существующих backup-манифестов.
3. Добавить синтетические проверки повреждённого первого backup, повторного
   применения, неизвестной версии, конкурентного изменения файла и путей.
4. Добавить небольшой каталог перевода и выборочный статический экспорт;
   проверить JSON, Unicode, идентификаторы, placeholders и отсутствие перевода.
5. Написать безопасную документацию вместо публикации сырых отчётов и дампов.
6. Проверить синтетические и локальные тесты, воспроизводимость исходного патча,
   неизменность установки и backup; проверить staged-файлы и Private после push.

Отдельное read-only ревью выполняется после реализации; основной агент проверяет
замечания и повторяет затронутые проверки. Сопутствующий рефакторинг не требуется.
