# Адаптация шрифта

Работающий механизм в `build_prototype.py` сохранён: из DefineFont3 ID 1
из собственной оригинальной копии SWF строится отдельный DefineFont3 ID 6000.
DefineText 3016 ссылается на новый font ID. Исходные шрифты не заменяются.
Ресурсы извлекаются при сборке только в памяти; результат SWF остаётся локальным.

Н/а/с/р/о используют побайтовые копии H/a/c/p/o с исходными advances.
Для т и к уменьшены T/K; и и й строятся из зеркального уменьшенного N,
й получает кратку. Рецепты сохраняют штрихи и засечки; размер текста 24 px,
цвет, положение, фильтры размещения и остальные игровые ресурсы сохраняются.
Проверка сравнивает все остальные теги и геометрию шрифта.

Четыре буквы т/к/и/й отличаются от полноценного оригинального начертания.
Новый шрифт покрывает только девять разных букв текущего заголовка, без новых
alignment zones. Офлайн contours preview не доказывает антиалиасинг AIR,
маски и фильтры. Скриншот предыдущего успешного запуска хранится локально в
`artifacts/runtime-options.png`. Здесь новая runtime-проверка не проводилась.

Для полного алфавита расширять существующие рецепты по контексту и проверять
метрики; не подменять подход системным шрифтом. Pillow и локальные OFL-референсы
нужны только для опционального `--preview`, не для самого патча.
Оригинальные глифы, адаптированные шрифты и preview не включаются в Git.
Право на их распространение не подтверждено.

## Полужирное начертание для локального меню

`localization_fonts.py` расширяет DefineFont3 по локальному JSON: ключи — новые
символы, рецепт задаёт `donor` и опциональные `sx`, `sy`, `tx`, `ty`, либо `parts`
из таких доноров. `contours` допускает местные дополнительные контуры; составной
рецепт задаёт `advance`. Контуры состоят из M/L/Q; координаты и advance — в font
units. Рецепты, полученные из игровых ресурсов, не включаются в Git.

Этап 3 использует embedded bold font255 для подписей, кнопок и программно
созданных подсказок. Regular font1 остаётся исходным; заголовок использует прежний
font6000. Полужирное начертание дополнено 54 требуемыми кириллическими символами.
Латинские глифы и их метрики/kerning сохраняются по Unicode-коду. Кириллица
вставляется в отсортированную таблицу перед высокой пунктуацией. Сборщик проверяет
все статические ссылки, включая вложенные sprites, и отказывает, если вставка
изменит значение существующего индекса. В поддерживаемом оригинале высокой
пунктуации в статических записях не обнаружено.

DefineFontAlignZones перестраивается в том же порядке кодов: исходные записи
сохраняются, новые имеют два нулевых FLOAT16-парных диапазона и отключённую маску.
Формат — [спецификация Adobe SWF19, DefineFontAlignZones](https://open-flash.github.io/mirrors/swf-spec-19.pdf),
подтверждён [реализацией Apache Royale](https://github.com/apache/royale-compiler/blob/develop/compiler/src/main/java/org/apache/royale/swf/io/SWFWriter.java).
Исходное сглаживание латиницы сохраняется; качество gridfit кириллицы не доказано.

Новые глифы используют исходные латинские контуры, уменьшенные прописные буквы,
отражения и композицию штрихов/засечек. Некоторым буквам свойственно приближение
малой прописной формы; это остаётся предметом визуального сравнения. Системной
гарнитурой декоративный шрифт не заменён. Контурный preview хранится в
`artifacts/options-glyph-preview.png` локально и не является игровым скриншотом.

Проверяются отсутствие пропущенных глифов, метрики, горизонтальные границы,
вертикальный ink относительно исходного ascent/descent и ограничение высоты поля.
Для переносимых подсказок оценивается число строк с запасом для динамических
значений. Это консервативная офлайн модель: фактические переносы, фильтры, цвет,
позиция baseline и читаемость на исходном масштабе требуют runtime-проверки.
