# Адаптация шрифта

Работающий механизм в `build_prototype.py` сохранён: из DefineFont3 ID 1
из собственной оригинальной копии SWF строится отдельный DefineFont3 ID 6000.
DefineText 3016 ссылается на новый font ID. Исходные шрифты не заменяются.
Ресурсы извлекаются при сборке только в памяти; результат SWF остаётся локальным.

Н/а/с/р/о используют побайтовые копии H/a/c/p/o с исходными advances.
Для т и к уменьшены T/K; и и й строятся из зеркального уменьшенного N,
й получает кратку. Рецепты сохраняют штрихи и засечки; размер текста 24 px,
цвет, положение, фильтры размещения и остальные игровые ресурсы сохраняются.
Проверка сравнивает все остальные теги и геометрию шрифта.

Четыре буквы т/к/и/й отличаются от полноценного оригинального начертания.
Новый шрифт покрывает только девять разных букв текущего заголовка, без новых
alignment zones. Офлайн contours preview не доказывает антиалиасинг AIR,
маски и фильтры. Скриншот предыдущего успешного запуска хранится локально в
`artifacts/runtime-options.png`. Здесь новая runtime-проверка не проводилась.

Для полного алфавита расширять существующие рецепты по контексту и проверять
метрики; не подменять подход системным шрифтом. Pillow и локальные OFL-референсы
нужны только для опционального `--preview`, не для самого патча.
Оригинальные глифы, адаптированные шрифты и preview не включаются в Git.
Право на их распространение не подтверждено.
