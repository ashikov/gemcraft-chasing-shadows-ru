# PR #34: иллюстрированная карта журнала

**GRAPHICS: INTEGRATED; RUNTIME: NOT TESTED.** Воспроизводимый графический рецепт
закрывает десять подтверждённых текстовых областей первого разворота, сохраняя
двенадцать строк. Он рассчитан на единственный проверенный оригинал с SHA-256
`c8eadc03a7e607086998695f7696ec22dd90d7b7859e3d10cdfabf40fc7bbad5`.
Игровые JPEG, PNG и SWF в Git не хранятся. Авторские подписи, координаты,
хеши, параметры и guards находятся в
[`pr34-journey-map.json`](../translations/plans/pr34-journey-map.json),
код — в [`journey_map_localization.py`](../journey_map_localization.py).

## Содержание и смысл

Оригинал заново извлечён из подтверждённого backup и просмотрен в полном размере.
Сюжетные подписи сопоставлены с каноническими записками, а имена — с глоссарием.
`source_sha256` каждой области — SHA-256 UTF-8 визуальной транскрипции;
между строками двухстрочных надписей используется один LF. Это хеш транскрипции,
а не извлечённой текстовой записи: в JPEG нет отдельных строк/глифов.
Основной guard изображения — SHA исходного JPEG и всего payload.
Полная английская транскрипция остаётся только в `local/pr34/map/`.

## Формат и адресная интеграция

Исходный ресурс: **DefineBits, tag 6, character 678, top-level path `[750]`**,
1440×868. Его payload — UI16 character ID и полноценный baseline JFIF JPEG
с собственными DQT/DHT. Единственный JPEGTables, `[286]`, пустой;
склеивание таблиц, удаление SOI/EOI и неявная подмена формата не нужны.
Проверка `jpeg_metadata` принимает ровно один законченный baseline JPEG,
проверяет длины маркеров, размеры и собственные таблицы. Реальная загрузка
и декодирование дополнительно проверяются Pillow.

Рецепт сохраняет **tag 6 и character 678**. Новый JPEG также самодостаточен;
его повторное чтение подтверждает JPEG/RGB/1440×868. Это узкая поддержка
наблюдаемой упаковки данного оригинала, а не универсальная поддержка всех
вариантов DefineBits и непустых внешних таблиц.

Цепочка использования сохранена: спрайт **813, кадр 0** → PlaceObject3
character **680** → спрайт **680** → DefineShape **679**, активная bitmap-заливка
№2 → bitmap **678**. Guards проверяют исходные payload shape679 и sprite680,
а также два размещения первого кадра sprite813. Локальный тест сериализации
проверяет побайтовое сохранение **всех остальных raw SWF-тегов**. Код не меняет
размеры, матрицы, ссылки, кадры, ActionScript или другие изображения.

`localize_map_tags(tags, font_bytes, plan['journey_map'])` возвращает новый
список тегов и отчёт; вызов выполняется до добавления новых шрифтовых тегов,
чтобы исходный path `[750]` оставался проверяемым. План содержит пустые
`entry_ids`: двенадцать растровых строк не выдаются за обычные ABC-переводы.
`validate_map_recipe` проверяет авторские данные без импорта Pillow.

## Восстановление фона и рисование

В пределах десяти узких исходных областей чёрные буквы выделяются по яркости,
коричневые — по цветности. Маска расширяется на один пиксель, чтобы убрать
антиалиасинг. Восстанавливаются **только пиксели маски**: каждый её пробег
интерполируется между соседними неизменными пикселями той же строки.
Это сохраняет направленность фактуры и не создаёт прямоугольной заплаты.

Применяется закреплённая **Alegreya Regular, weight 400**, SHA-256
`ba5564634b93a8f8ba57b48cd4f1ae7417d2b4656fbac779028679b00de3cf12`.
Текст рисуется с тройным разрешением и уменьшается Lanczos; региональные
подписи сохраняют коричневый цвет и наклон. Размеры, центры, две явные пары
строк и допустимые границы закреплены в плане. Подписи не пересекают семь
защищённых прямоугольников рисунков. Маршруты не перерисовываются.

До JPEG-кодирования подтверждено:

- вне объединения маски восстановления и альфа-масок новых букв RGB-пиксели
  совпадают с исходными;
- семь защищённых рисунков сохранены целиком;
- 4010 цветных пикселей сердцевин маршрутов сохранены;
- все десять контуров входят в закреплённые области при масштабах 1 / 0,75 / 0,5.

Маска содержит 19 766 пикселей. Проверка поймала ранний дефект прототипа:
маска подписи `possessed` захватывала 13 пикселей основания башни. Верхняя
граница сужена с 583 до 588; отдельный регрессионный тест воспроизводит
повреждение и требует отказа генератора.

JPEG сжимается повторно с исходными таблицами квантования, subsampling 2,
без progressive/optimize. Поэтому **готовый JPEG не сохраняет пиксели вне масок
побайтово**. В данном кандидате среднее абсолютное отклонение канала вне масок
после кодирования — 0,124 из 255, максимальное — 28. Это эффект lossy-кодека,
не изменение маршрутов алгоритмом рисования. Полная метрика и локальные
изображения находятся в `local/pr34/map/jpeg-lossy-diff.json` и соседних файлах.

## Воспроизведение и проверки

Рендерер fail-closed сверяет версии: **Pillow 12.3.0, libjpeg API 6.2,
libjpeg-turbo 3.1.4.1, FreeType 2.14.3**. Pillow уже является необязательной
зависимостью preview проекта; дополнительных пакетов или сервисов рецепт
не вводит. Для графической сборки нужна именно эта проверенная среда.
Другие версии отклоняются; переносимость на них не заявляется.

```sh
python journey_map_localization.py \
  --source /path/to/confirmed/original.swf \
  --alegreya-font 'reference-fonts/alegreya/Alegreya[wght].ttf' \
  --output-dir local/pr34-map-reproduction
```

Команда создаёт новый ignored-каталог с JPEG и отчётом, не изменяет SWF,
установку или сохранения и не запускает игру. Для повторения нужен другой
новый каталог. Рецепт и накопительный pipeline используют один генератор.

Закреплённый новый JPEG SHA-256:
`168f562c1afdb55728d2f4482d20affb824243b1ab6d527274119c3163709b67`.
Исходный JPEG SHA-256:
`3fdb11eacb6b7ac71c75f1ca2a66621dd6882e5c46bf4b87174db1e3d2afcd0d`.
Хеш JPEG не является SHA всего накопительного SWF.

Выполнено **19 PASS, 0 FAIL, 0 SKIP**: 13 синтетических и 6 локальных тестов
`tests/test_journey_map.py`, `tests/test_journey_map_local.py`.
Проверены детерминированность двух генераций, реальное декодирование,
запись/повторное чтение SWF, точные ссылки и сохранность остальных тегов,
контуры при трёх масштабах, отклонение повреждённого JPEG, неверных хешей,
шрифта, адреса, layout и повреждения защищённого рисунка. Ruff и compileall
этого модуля прошли. Для локальных тестов задаются `GEMCRAFT_ORIGINAL`
и при необходимости `GEMCRAFT_ALEGREYA_FONT`; отсутствие оригинала — SKIP,
который не считается успешной проверкой.

## Ограничения визуальной приёмки

Полный JPEG и уменьшенные офлайн-копии просмотрены локально. Удалённые
английские буквы не оставлены видимыми, прямоугольных заплат нет, исходная
география и условные знаки сохранены в проверенных областях. Это статическая
оценка изображения, а не игровая приёмка страницы.

Alegreya сохраняет характер книжной антиквы, но отличается от исходного
декоративного начертания. Художественное соответствие, сглаживание AIR,
фильтрация bitmap и читаемость мелких подписей, особенно при 0,5,
остаются **RUNTIME-UNVERIFIED**. Повороты региональных подписей заданы одним
углом для каждой строки; исходная нерегулярная линия отдельных букв
не воспроизводится. Приёмка в игре должна оценить эти отличия до релиза.
Другие иллюстрации журнала этим узким рецептом не проверены.
