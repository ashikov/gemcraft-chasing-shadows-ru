## Запуски и безопасность

Новых запусков — **2**, оба в новой AIR-копии `GCCS.PR35.20261031`.
`r01`: PID 51376, start `2026-10-31T04:38:00.3322825Z`; копия PR25-профиля,
F1/победа, стена, штатный выход из выносливости и карта.
`r02`: PID 24644, start `2026-10-31T04:44:37.8721944Z`; повторная загрузка,
рекорд 100 и экран достижений. Оба процесса закрыты точным WM_CLOSE;
после каждого подтверждено отсутствие игровых процессов и сохранён новый immutable
снимок тестового store. Независимый просмотр подтвердил читаемость стены,
совета №13 и показанных итогов; кадр r01/021 сам по себе не доказывает hover-ответ.
Ответ карты и новый рекорд отдельно показаны r02/003.

Операционное отклонение r01: два локальных вспомогательных скрипта проверки
процессов остановились из-за пропущенного ExecutionPolicy-параметра, а следующая
команда запуска не была связана с ними условием успеха. Этот preflight не засчитан
как PASS. Сам launch guard проверил SWF/EXE, AIR ID и отсутствие игры; до игрового
ввода выполнена полная исправленная проверка ресурсов/данных/точного процесса.
В r02 preflight и запуск уже связаны условием успеха, все проверки прошли до старта.
Это отклонение не скрывается и не приписывается игре.

До запуска создан и проверен отдельный immutable backup 11 исходных файлов;
занятый слот проверен checksum/roundtrip, пустые слоты оставлены пустыми.
Копирование исходного профиля и изменения самой игрой касались только нового store;
ручных изменений save не было. AutoCloud marker не копировался; локальные mappings
не включают тестовый AIR ID, Steam Cloud не перенастраивался. Удалённое состояние
сервера не проверялось; отдельный AIR ID не является изоляцией Steam-аккаунта.

Финальная сверка: **25/25 ресурсов Steam-установки PR25, 11/11 исходных файлов
и 11/11 immutable backup совпали**. Изолированный SWF восстановлен штатным
restore до оригинала. Исходные пользовательские файлы не требовали восстановления.
Совместимость сохранения проверена в направлении PR25 → RC на копии; запуск
записанного RC-save под PR25 обратно не выполнялся. Откат SWF не заменяет save.

## Установка и идентичность кандидата

Проверенная процедура с командами и точками безопасного отказа:
[README](../README.md#проверенный-переход-pr25--релизный-кандидат).
Текущий builder не воспроизводит исторический PR25 даже после reconcile workspace;
это ограничение tooling. Для точного возврата сохранённого PR25 проверен существующий
`apply_patch_file` с обоими полными SHA guards; текущий RC поддерживает обычный CLI.
Новый installer не создавался, guards не ослаблялись. Для обновления пользовательские
сохранения перезаписывать не требуется; их независимый backup следует сохранить.

- Оригинал: `c8eadc03a7e607086998695f7696ec22dd90d7b7859e3d10cdfabf40fc7bbad5`.
- Установленный PR25: `a10aa184dea912875b0b5c87da2a10f67e0072f7f24cb4963caabba1a543e771`.
- Финальный RC: `0bf6d4ae5bc0764bfc84d589892c1288de71062673f663d532e9e434b22ebacf`.

GO обоснован воспроизводимой сборкой, проверенным основным циклом и сохранением
на копии, безопасным файловым переходом/откатом и отсутствием обнаруженных
существенных дефектов. Новые этапы локализации и дальнейшие игровые запуски не нужны
для этого решения. Git HEAD, Draft PR и CI фиксируются в описании PR и итоговом отчёте.
