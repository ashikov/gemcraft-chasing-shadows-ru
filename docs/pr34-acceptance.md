## AdviceOracle

Оригинальный адрес `abc.4175.1441.39`, `AdviceOracle.advicesRaw`:
base64 → zlib → UTF-8 → split(CR). Это 60 непустых записей с 59 CR,
без внутренних управляющих символов и завершающего разделителя.
`m1284` выполняет декодирование, `uncompress`, `readUTFBytes`.
`m1442` создаёт индексы 0–59, перемешивает при исчерпании, выдаёт и удаляет
индекс только при исходных `NORMAL && Prefs.showAdvices` и пороге прогресса.
Оригинальные методы декодирования и выбора сохранены.

Единственный потребитель — `m465@1147`, запись в `tfAdvice.text@1151`;
`m3533` меняет alpha. Шрифт выбирается перед присвоением текста.
Исходный слот `edit.2013`: 773,95×56,6 px, 16 px, wordWrap/multiline,
leading 2 px. Все 60 советов укладываются максимум в две строки;
наибольшая строка 759,95 px при доступных 769,95 px, высота 45,56 px
до padding 4 px. Геометрия поля не меняется. Масштабы 1 / 0,75 / 0,5
проверены офлайн. В AIR приняты советы №14, №48 и №51: каждый показан
одной полной строкой при 1. Остальные 57 текстов и их переносы ещё не приняты.

В inventory адресный адаптер раскрывает только этот guarded payload;
Git хранит читаемый русский текст с CR и decoded source SHA. При сборке
рецепт воспроизводит исходную упаковку побайтово и упаковывает перевод.
Проверяются raw/decoded hashes, порядок, UTF-8, число и границы записей,
детерминированность, повреждение, лишние данные и предел распаковки 64 KiB.
Английский массив остаётся в ignored workspace.
