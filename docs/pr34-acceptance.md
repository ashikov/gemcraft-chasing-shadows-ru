## AdviceOracle

Оригинальный адрес `abc.4175.1441.39`, `AdviceOracle.advicesRaw`:
base64 → zlib → UTF-8 → split(CR). Это 60 непустых записей с 59 CR,
без внутренних управляющих символов и завершающего разделителя.
`m1284` выполняет декодирование, `uncompress`, `readUTFBytes`.
`m1442` создаёт индексы 0–59, перемешивает при исчерпании, выдаёт и удаляет
индекс только при исходных `NORMAL && Prefs.showAdvices` и пороге прогресса.
Оригинальные методы декодирования и выбора сохранены.

Единственный потребитель — `m465@1147`, запись в `tfAdvice.text@1151`;
`m3533` меняет alpha. Шрифт выбирается перед присвоением текста.
Исходный слот `edit.2013`: 773,95×56,6 px, 16 px, wordWrap/multiline,
leading 2 px. Все 60 советов укладываются максимум в две строки;
наибольшая строка 759,95 px при доступных 769,95 px, высота 45,56 px
до padding 4 px. Геометрия поля не меняется. Масштабы 1 / 0,75 / 0,5
проверены офлайн; AIR-переносы и читаемость ещё не приняты.

В inventory адресный адаптер раскрывает только этот guarded payload;
Git хранит читаемый русский текст с CR и decoded source SHA. При сборке
рецепт воспроизводит исходную упаковку побайтово и упаковывает перевод.
Проверяются raw/decoded hashes, порядок, UTF-8, число и границы записей,
детерминированность, повреждение, лишние данные и предел распаковки 64 KiB.
Английский массив остаётся в ignored workspace.

## Recovery и малые сообщения

`m334@313` создаёт четыре строки с полем и двумя значениями опыта,
`@364` — сообщение нового рекорда, `@728` — восстановленные фрагменты.
В последней фразе адресный `swap` переставляет только строковый префикс
и уже вычисленное количество. `@690` становится пустой строкой;
условная plural-ветвь и все числовые операции остаются исходными.
Полные выражения проверены обеими ветвями `Prefs.lotsOfDigits`, включая
0/1/2/5/11/21/101/1000 и большие значения форматтера.

`McFloaterPanel.addTextField`, m3442, получает ранний выбор шрифта:
Alegreya только для 17 точно выбранных сообщений/префиксов;
для других значений остаётся исходная гарнитура. Вставка меняет только
`local5.font` до `defaultTextFormat`, `text`, width/height; размер, цвет,
выбор строк и расположение самой панели сохраняются.
Коды угловых кнопок карты, ID, условия Mods и игровые состояния не меняются.
Кнопка обучения использует существующий field binding.

У XP пересчитаны реальные глифовые контуры, а не только max_width:
локальные границы в frame — [803,1087,99,180] twips, рамка 90×34 px;
нижняя граница подписи 320 twips выше начала числового XP 335 twips.
Соседние shapes и размещения сохранены. «Опыт» при исходных 6 px
помещается в реальный layout, хотя шире прежнего DefineText bounds.
У маркера волны проверены все 418 исходных конструкторов достижений:
требование отсутствует либо не больше 24. Эти реальные значения входят
в слот 26,1 px; недостижимые здесь четырёхзначные числа не используются
как модель вместимости.

## Карта и остаточный аудит

Графический рецепт, смысл всех подписей, защита географии, формат JPEG,
маски, потери повторного JPEG-сжатия и художественные ограничения описаны
в [отчёте карты](pr34-map.md). Сохранены tag6/character678, пустой JPEGTables,
shape679, sprite680 и размещения первого разворота. До JPEG-кодирования
пиксели вне масок, семь рисунков и 4010 цветных пикселей маршрутов совпадают.
Повторное JPEG-сжатие lossy; побайтовое равенство декодированных пикселей
после сжатия не заявляется. Сам JPEG и производные SWF в Git не входят.

[Адресная матрица всех 55 компонентов](pr34-component-audit.json):
**12 COVERED / 43 TECHNICAL**, 0 доказанных UNREACHABLE,
0 оставшихся NEEDS TRANSLATION среди этих конкретных присваиваний.
Для всех строк runtime PR34 — NOT TESTED. Назначения, placement и source SHA
перепроверены по оригиналу и независимо рассмотрены. Общие имена `tf`,
`tf1/tf2` не использовались как доказательство тождества разных объектов.
Это ограниченный статический аудит, не доказательство отсутствия английского
на всех экранах или в других иллюстрациях.

## Runtime, установка и откат

Запуск **не выполнен**. До любой операции с тестовыми сохранениями создан
новый отдельный backup 11 исходных пользовательских файлов:
`local/pr34/user-data-original/manifest.json`, размер/SHA/побайтовая сверка,
файлы 0444 и каталог 0555. Исходные пользовательские данные не записывались.

Подготовлена отдельная копия 25 ресурсов в Windows Temp,
`gemcraft-pr34-20261026`, AIR ID `GCCS.PR34.20261026`.
В descriptor заменён только ID; исходный store `GCCS` не используется.
Кандидат установлен hash-guarded инструментом только в эту тестовую копию;
все 25 ресурсов сверены, путь rollback закреплён локальным манифестом.
Пользовательские сохранения в тестовый store не копировались.
Steam Cloud не перенастраивался. Перед разрешённым запуском обязательны
повторная проверка отсутствия игры, всех ресурсов/backup, изоляции Cloud
и исходных данных; одного отдельного AIR ID недостаточно для утверждения,
что любые интеграции Steam изолированы.

Сценарий первого запуска: загрузочный совет; обычные UI/Mods без изменения
кодовых последовательностей; кнопка обучения; первый разворот журнала;
сохранение выносливости и recovery только при достижимом тестовом состоянии.
Для искусственного recovery может потребоваться отдельное разрешение
на изменение **изолированных** сохранений. Исходные сохранения не использовать.
Проверить масштабы 1 / 0,75 / 0,5, обрезание, фон и стиль карты, переносы
советов, все строки панелей, закрытие/повторное открытие и переходы экранов.
После запуска — штатное завершение точного тестового процесса, rollback
тестового SWF и повторная сверка исходных данных с immutable backup.
Подготовленный сценарий не отмечается выполненным.

типов святилищ, поздние состояния монстров/волн, фактическая постройка усилителя,
полная панель стены, все страницы справки/обучения/журнала.

Перечисленные состояния не объявляются непереведёнными без доказанного
видимого английского текста, но остаются непроверенными для релиза.
