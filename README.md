# GemCraft: Chasing Shadows — русификация

Неофициальный проект русской локализации для личного использования.
Правила для coding agents: [AGENTS.md](AGENTS.md).
Для локализованного меню выбрана **Alegreya Regular 400 / Bold 700**.
Кандидат настроек использует отдельные встроенные шрифты и 142 подготовленных
адресных перевода. Исправленный кандидат прошёл отдельную runtime-проверку всех четырёх
разделов настроек: подписи, заголовок, подсказки и динамические значения видны
без обнаруженного обрезания. Первый кандидат не открывал меню из-за ошибки
`ReferenceError #1056` в ABC-привязке `TextFormat.font`; причина исправлена.
v6 и не установленная v7 остаются историческими результатами.

Поддерживается только проверенный Steam SWF игры 1.0.6 (build 734216,
AppID 296490), определяемый **по SHA-256**, а не по имени или номеру версии:

```text
original: c8eadc03a7e607086998695f7696ec22dd90d7b7859e3d10cdfabf40fc7bbad5
prototype: 41bb1a40cf95f8b48a9829df130ee492f07c8dcb2539070b11c07fc181f592e9
```

## Структура и требования

- `build_prototype.py`, `swf_geometry.py`: существующие SWF/font/text инструменты;
  добавление DefineFont3 и замена единственного DefineText 3016.
- `alegreya_localization.py`, `alegreya_fonts.py`, `abc_font_binding.py`:
  основная сборка меню с отдельными DefineFont3 и адресной привязкой форматов ABC.
- `addressed_localization.py`, `abc_patch.py`:
  проверка адресов и изолированные замены переводов.
- `localization_fonts.py`: исторический способ воспроизвести v1–v7.
- `install_patch.py`, `restore_game.py`: hash-guarded apply/restore и backup.
- `preview_typography.py`: необязательный офлайн просмотр контуров.
- `verify_experiment.py`: read-only проверка установленного патча.
- `extract_strings.py`, `inventory_strings.py`, `abc_inventory.py`: read-only
  инвентаризация статических/редактируемых SWF-текстов и ABC.
- `translation_catalog.py`, `localization_workspace.py`, `translations/`:
  исторический пример, локальная двуязычная работа, конфликты и минимальная проекция.
- `versioned_catalog.py`, `localization_project.py`: приватный канонический каталог
  ручных данных, восстановление workspace и воспроизводимая накопительная сборка.
- `translations/catalog.json`, `translations/build-manifest.json`, `translations/plans/`:
  русский перевод, порядок и SHA планов; `translations/editorial/` — глоссарий и стиль.
- `tests/`, `.github/workflows/`, `docs/`: проверки и документация.
- `local/extraction/`, `backups/`, `output/`, `artifacts/`, `reference-fonts/`, старые отчёты и дампы:
  **только локально**, исключены из Git.

Нужны Python 3.11+, собственная установленная Steam-копия игры и доступ к её
файлам. Сборка Alegreya требует закреплённый `fontTools` из
`requirements-build.txt`; тесты требуют pytest, проверка стиля — Ruff.
Для необязательного preview нужен Pillow. Историческая сборка и файловые
операции apply/restore используют стандартную библиотеку.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
```

## Восстановление накопительной сборки из Git

В приватном `ashikov/gemcraft-chasing-shadows-ru` разрешены авторский русский
перевод, редакторские данные, минимальные адресные метаданные и необходимые планы.
Владелец принимает юридический риск; разрешение правообладателя и право публичного
распространения не заявляются. SWF, оригинальные ресурсы, дампы и полный двуязычный
workspace в Git не входят. Подробнее — [правовой статус](docs/legal.md).

Канонический `translations/catalog.json` сохраняет 1934 авторских перевода:
1809 выбранных накопительными планами и 125 дополнительных. Двенадцать планов
PR #3–#13 и их порядок закреплены в `translations/build-manifest.json`.
`translations/ru.json` остаётся историческим примером. Локальный workspace
восстанавливается из оригинала и Git-каталога, английские `source` извлекаются
из собственной копии SWF. Для чистого клона нужны только этот оригинал,
закреплённый TTF и Python-зависимости.

```sh
git clone git@github.com:ashikov/gemcraft-chasing-shadows-ru.git gemcraft-ru
cd gemcraft-ru
# До merge PR #14 переключитесь на его ветку.
git switch feat/pr14-versioned-translations
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
# Загрузите именно официальный закреплённый шрифт.
mkdir -p local/inputs
curl --fail --location \
  'https://raw.githubusercontent.com/google/fonts/199711f8c8d2cafc88f26c174152abfa18eb62c3/ofl/alegreya/Alegreya%5Bwght%5D.ttf' \
  --output 'local/inputs/Alegreya[wght].ttf'
python localization_project.py validate
python localization_project.py restore --source /path/to/original.swf \
  --output-dir local/restored
python localization_project.py check --workspace local/restored/workspace.json \
  --inventory local/restored/inventory.json
python localization_project.py build --source /path/to/original.swf \
  --alegreya-font 'local/inputs/Alegreya[wght].ttf' --output-dir local/candidate
```

Шрифт сверяется с `fonts/alegreya/provenance.json`: SHA-256
`ba5564634b93a8f8ba57b48cd4f1ae7417d2b4656fbac779028679b00de3cf12`.
Ожидаемый накопительный SWF PR #13:
`8222c9127774620e6caed18120772f7aad8c68a46d766192a0213c05e1786fe7`.
Сборка восстанавливает собственный workspace, применяет планы в закреплённом
порядке и проверяет записанный кандидат штатным валидатором. Новый каталог вывода
защищает существующие данные. Проверки не запускают игру и не меняют установку;
визуальная приёмка новых экранов остаётся отдельной задачей.

После правки перевода валидируйте workspace, экспортируйте в новый файл с
`versioned_catalog.py export --previous translations/catalog.json
--base-receipt local/restored/catalog-origin.json`, просмотрите изменения,
обновите канонический каталог и проверьте синхронизацию. Receipt создаётся при
восстановлении; экспорт отклоняет устаревший workspace, если каталог изменился. Коммитьте его
вместе с необходимым планом, manifest и тестами. Полные команды и защита от потери
ручных данных — [в workflow переводов](docs/translations.md#приватный-workflow).

## Подготовка и применение

Закройте игру перед изменением файлов. Ни один публикуемый инструмент её не
запускает. Для любого будущего GUI/runtime запуска требуется отдельное явное
согласие пользователя. Сначала используйте копии и проверьте результат.

Исходный SWF получают из собственной установки. Если патч уже установлен,
используйте проверенный оригинальный backup, а не изменённый SWF. Не скачивайте
игровые ресурсы из проекта: их здесь нет. Не переносите существующие backup и
манифесты: они содержат точные локальные пути.

```sh
# Укажите свой путь к оригиналу: установленному SWF либо его backup.
python build_prototype.py --source /path/to/original/gc-cs-steam.swf
# Результат: output/gc-cs-steam.ru.swf и static-validation.json.
# Только если установка оригинальная и вы намерены изменить её:
python install_patch.py apply --game-file /path/to/game/gc-cs-steam.swf
```

Путь к игре задаётся `--game-file` либо `GEMCRAFT_GAME_FILE`; изменяющие команды
не выбирают установку автоматически. `--candidate` и `--backup-dir` позволяют
задать другие локальные пути; backup должен быть вне каталога игры.
Сборка принимает `--output-dir` и отказывается перезаписывать исходник.

Apply заново проверяет структуру кандидата и SHA исходника, создаёт backup
эксклюзивно, сверяет его побайтово, записывает манифест и атомарно заменяет SWF.
Первый backup никогда не перезаписывается. Уже изменённый или неизвестный SWF
отклоняется. Повреждённый backup тоже блокирует установку.

При установленном патче новый apply запрещён: сначала проверьте старый
манифест и сохраните предыдущий кандидат, затем восстановите оригинал штатным
restore. Не подменяйте модифицированный SWF напрямую. Локальная последовательность
перехода и отката должна быть сначала проверена на изолированной копии.

## Восстановление и read-only проверка

Используйте манифест, выведенный apply. Откат не требует пересборки шрифта:

```sh
python restore_game.py --game-file /path/to/game/gc-cs-steam.swf \
  --manifest /path/to/backups/manifest-HASH.json
# Эквивалент: python install_patch.py restore с теми же аргументами.
python verify_experiment.py --game-file /path/to/game/gc-cs-steam.swf \
  --backup-dir /path/to/backups --report /path/to/new-verification.json
```

Restore проверяет оригинальный backup по размеру и SHA, разрешает замену только
известного установленного патча; повторный откат безопасен. После обновления
Steam неизвестный файл не перезаписывается. Не редактируйте манифест вручную.
Read-only verifier опционально принимает `--inventory file-inventory.json`:
тогда проверяет также неизменность остальных файлов по локальной инвентаризации.
Без inventory проверяет только SWF и backup. Это не runtime-проверка.
Отчёт создаётся только по новому пути: прежние свидетельства не перезаписываются.

## Проверки

```sh
python -m pytest -q -m 'not local'
python -m ruff check .
python translation_catalog.py translations/ru.json
python localization_project.py validate
python -m compileall -q *.py tests
# Локальная интеграция: читает оригинал, пишет только во временные каталоги.
GEMCRAFT_ORIGINAL=/path/to/original/gc-cs-steam.swf python -m pytest -q -m local
```

Локальные тесты также находят существующий backup в `backups/`. При его
отсутствии проверки, требующие оригинала, пропускаются. GitHub Actions выполняет
только синтетические тесты, lint, компиляцию и проверки Git-каталога/manifest,
без игры и оригинального SWF; это не полноценная локальная интеграция.

## Меню с Alegreya

Сборка читает проверенные адреса из существующего **локального** workspace и
официальный TTF, сверяемый с
[`fonts/alegreya/provenance.json`](fonts/alegreya/provenance.json). При установке
повторно проверяется весь кандидат. Пример предполагает уже проверенный оригинал
и новый каталог вывода:

```sh
python alegreya_localization.py --source /path/to/original/gc-cs-steam.swf \
  --workspace local/extraction/translation-workspace.json \
  --plan local/extraction/options-plan.json \
  --alegreya-font 'reference-fonts/alegreya/Alegreya[wght].ttf' \
  --output-dir output/options-alegreya-candidate
# После проверки оригинальной установки; для обновления сначала restore:
python install_patch.py apply --game-file /path/to/game/gc-cs-steam.swf \
  --candidate output/options-alegreya-candidate/gc-cs-steam.ru.swf \
  --workspace local/extraction/translation-workspace.json \
  --plan local/extraction/options-plan.json \
  --alegreya-font 'reference-fonts/alegreya/Alegreya[wght].ttf'
python verify_experiment.py --game-file /path/to/game/gc-cs-steam.swf \
  --report /path/to/new-alegreya-verification.json \
  --workspace local/extraction/translation-workspace.json \
  --plan local/extraction/options-plan.json \
  --alegreya-font 'reference-fonts/alegreya/Alegreya[wght].ttf'
```

`--output-dir` должен быть новым: сборка не перезаписывает кандидаты и отчёты.
Старый `--font-recipes` остаётся только для воспроизведения v1–v7 и отката;
с `--alegreya-font` он несовместим. Без локальных аргументов действует прежний
минимальный рецепт заголовка. Формат адресов —
[в документации переводов](docs/translations.md).

Исходные font ID 1/255 и alignment zones сохраняются побайтово. Новые ID
6001/6002 и адресные ABC-вставки предназначены для выбранных элементов
локальных планов; runtime-проверка PR #3 покрывала только настройки.
В отдельно разрешённом запуске проверены все четыре раздела,
подсказки с числами и знаками процента, а также титульный экран и карта за
пределами меню. Игра закрыта без изменения десяти файлов настроек и сохранений.
Офлайн-проверки и этот запуск не покрывают все возможные игровые состояния;
уведомление сброса обучения имеет неподтверждённую достижимость и использует
общий ресурс сообщений.

Инструменты этапа 2 сохраняют полный структурный локальный снимок DefineText/2,
DefineEditText и строк/использований ABC. Поиск видимых состояний требует проверки
связей и runtime; [статистика и пробелы](docs/string-inventory.md).
Произвольное HTML-переписывание и новые версии игры не поддерживаются.
Ограниченное расширение на главное меню и карту описано ниже.
ABC-релокация ограничена проверенными вставками в выбранные методы. Новые русские
переводы и необходимые планы сохраняются в приватном production-каталоге Git.
Оригиналы, диагностические материалы и скриншоты остаются локально; ограниченный
публичный allowlist не расширен.

Подробнее: [формат и извлечение](docs/translations.md),
[адаптация шрифтов](docs/fonts.md), [аудит](docs/audit.md),
[правовой статус](docs/legal.md).

## Накопительные планы экранов

Один кандидат собирается **из оригинала**, объединяя план настроек и новые
планы из `translations/plans/`. Штатный порядок зафиксирован manifest и применяется
через `localization_project.py build`; низкоуровневый CLI сохранён. Для отдельных
экспериментов повторяйте `--plan` для каждого этапа:

```sh
python alegreya_localization.py --source /path/to/original/gc-cs-steam.swf \
  --workspace /path/to/private/workspace.json \
  --plan /path/to/private/options-plan.json \
  --plan /path/to/private/main-menu-plan.json \
  --plan /path/to/private/map-plan.json \
  --alegreya-font 'reference-fonts/alegreya/Alegreya[wght].ttf' \
  --output-dir /path/to/fresh/candidate
```

Для штатных apply/verifier передайте единый объединённый план, полученный через
`localization_plan.merge_localization_plans`; их прежний CLI сохранён. Объединение
отклоняет повторные ID, адреса и привязки, несовместимые SHA и лишние layouts.
Настройки сохраняются, шрифты 6001/6002 добавляются один раз; расширение их
репертуара может изменить индексы глифов и SHA, сохраняя сами прежние контуры.

Поддерживаются выбранные однострочные DefineText/2 и ограниченный существующий
шаблон DefineEditText HTML: абзацы с одним font и необязательным bold,
включая justify и пустые разделители. Все font имеют единый размер. Разметка,
атрибуты, размеры и режим переноса защищены проверками; меняются текст и локальная
гарнитура. Многострочные статические записи поддерживаются только явным рецептом
`lines` плана: одна строка на каждый исходный record, порядок и число записей,
их смещения, цвета и высоты сохраняются. Строки, склеенные по порядку с
необязательным одиночным пробелом на стыке, обязаны точно воспроизводить перевод
workspace. Для невыровненных по центру записей строка не может выходить за
исходную правую крайнюю точку текста; `center: true` вместо этого сохраняет
ink-центр каждой строки, пересчитывая её смещение x (смещения y, цвета, высоты
и порядок записей сохраняются всегда). Матрица тега должна быть чистым переносом.
Произвольный Flash HTML отклоняется.
Адресные привязки ABC проверяют исходные инструкции и выражения чтения receiver.
Подсказки получают шрифт до расчёта геометрии с немедленным восстановлением
исходного формата; выбранные всплывающие панели пересчитывают размер после смены
гарнитуры. Общие методы рендеринга и игровые механики сохраняются.

Локальный этап главного меню/карты применяет 367 записей: настройки — 142,
главное меню со слотами, титрами и списком изменений — 93, навигация карты — 132.
Статус этапа **PARTIAL**: описания достижений внутри подсказки поля и панель
боевых черт остаются английскими. Общие ресурсы этих текстов также используются
в других областях; глобальная замена не применяется. Интерфейс нового кандидата
ещё не проверен в игре; положительная офлайн-компоновка не доказывает отображение.

Локальный этап обучающих панелей (`McTutorPanel`, спрайт 3608, 30 кадров)
добавляет 73 записи: 71 статический DefineText (из них 34 многострочных блока
с явными строками `lines` плана и центрированием по ink-центру строк) и два
одноабзацных HTML DefineEditText подписи продолжения. Все текстовые персонажи
кадров покрыты; кадр 10 текста не содержит. Статус этапа **NOT VERIFIED**:
панели открываются по мере прохождения, офлайн-проверки не доказывают
отображение; игровая приёмка требует отдельного разрешения на установку и запуск.

Локальный этап паузы и итогов боя добавляет 162 записи, сохраняя все 440
прежних: overlay потери фокуса, заголовки победы/поражения и двух исходов
«Выносливости», подписи статистики и 127 фрагментов её расшифровок, поле и
кнопки результата. Числовые поля, общий ресурс кнопок, неизменяемые разделители

Все состояния нового этапа — **NOT VERIFIED — ACCEPTED RISK**: выполнены только
офлайн-проверки текста, геометрии, глифов и ABC; игра не запускалась.
Итоговый накопительный кандидат содержит 602 записи.

Локальный этап навыков добавляет 117 переводов и один guarded empty suffix,
